# 题面生成模版

按本文件即可写出一份标准 OJ 题面（Markdown）。规范汇自：

- `fix/题目格式需求.txt`（章节骨架与版式）
- `fix/prompts/step3_system.txt` / `step3_user.txt`（正文、范围、I/O）
- `fix/prompts/step4_system.txt` / `step4_user.txt`（样例）
- `fix/AGENT_REWRITE.md`、`fix/需求梳理.txt` Step 5 拼接规则
- P4893 / P4894 原题面结构

生成顺序：**先写正文与 I/O（不含样例）→ 再造 2～4 组新样例 → 按下方空壳拼接成一篇 Markdown。**

---

## 一、生成前必须钉死

| 项 | 要求 |
|---|---|
| 算法核 | 目标、合法形态、最优解判定与原题/标程一致 |
| I/O 协议 | 行数、字段顺序、分隔符、多测/单组与标程一致（改写时另见第六节） |
| 字符集 | 输入输出里出现的字符必须与标程实际比较的字符相同（如代码认 `'0'`/`'1'`，题面不得改成 `L`/`R`）；只改字符的业务含义 |
| 范围数值 | 只允许改**记法**，禁止改到另一复杂度档 |
| 禁止 | 真实公司/品牌名、真人名；把关键规则只写在样例说明里 |

## 三、各节怎么写

### 1. 题名

短、贴题，点出核心对象或目标。不要照抄原平台标题或「小苯/小红」叙事。

### 2. 题目内容

1. **业务背景（2～5 句）**：角色、业务目标、规则从何而来；换场景、换术语、换自造定义名。标准术语不换（子段、子序列、前缀、树、边、卷积、dropout 等）。
2. **形式化定义**：变量定义完整；下标、闭区间、重边/自环/负数/重复值、多解规则写清。术语先定义再使用。
3. **数据范围（本节末尾，输入描述里再写一遍）**：用自然语言。记法必须与「对照题」对调：

| 对照题已有写法 | 本题必须写成 |
|---|---|
| $2\times 10^5$、$2e5$、$10^9$ | `200000`、`1000000000` |
| `100000`、`200000`、`1000000000` | $10^5$、$2\times 10^5$、$10^9$ |
| $10^9+7$ | `1000000007`（或反过来） |

禁止与对照题同一种记法。$2\times 10^5$ 只能对成 `200000`，不能写成 `100000`。

全新出题（无对照题）时：选定一种记法全文统一即可，不必对调。

可选：用 `**约束**` + 列表（如 P4893）；也可把范围写成正文末段（如 P4894）。原题没有该小标题就不要硬加。

### 3. 输入描述

- **ACM / 标准输入**（`input()`、`stdin`）：逐行说明。例：第一行两个整数 $n$ 和 $m$，接下来 $n$ 行……
- **力扣 / 函数参数**：参数列表。例：输入包含整数 $n$、字符串 $s$、整数列表 $nums$。
- 变量名、描述方式不要照搬原文；字段顺序与分隔必须与代码一致。
- 范围在本节再写一遍。

### 4. 输出描述

- 打印则写「输出……」；返回则写「返回……」。
- 写清行数、每行含义、空格分隔、Yes/No 大小写、多解时输出哪一种。
- 答案恒非负时可写「非负整数」，但不得改变判定。

### 5. 样例

- 输入/输出必须放在围栏代码块中，保持原始空格与换行。
- 必须能被标程直接跑出对应输出。
- **说明** 用 Markdown 列表；写规模、关键位置、计算步骤、为何得到该输出。分段，不要全挤在一行。说明只帮助理解，不引入新规则。
- **改写/拼接时禁止原样例**：整段输入相同不算新；只改空白、边顺序、一条边、一个数、说明都不算新；原样例中带字母或 `?` 的行不得作为新样例一行或子串；原样例中至少 3 个数的数据行不得原样复用。原样例只作排版参考。

---

## 四、版式硬规则

1. 行内公式 `$...$`，多行公式 `$$...$$`。
2. 题面（含样例说明）里的**阿拉伯数字**左右加反引号，编号/题号除外。例：`` $n = `4`$ ``、``输出 `0` ``。
3. 章节标题固定为上述中文，不要改成「题目描述」「Input」等。
4. 不要把样例写进「题目内容」；样例只出现在 `## 样例k`。
5. 若走仓库 `fix` 流水线的 JSON 中间件：LaTeX 反斜杠写成 `\\`（`$n \\le 10^5$`）。最终 `.md` 题面用正常单反斜杠。

## 六、改写题附加条款（无对照题可跳过）

- 文首必须有新中文题名；`# 题目内容` 等标题不改。
- 自造名、变量名整题替换，禁止混用新旧符号。
- I/O 字符集冻结；浮点精度、多解规则、Yes/No 大小写不改。
- 范围记法必须与原题对调，数值不变。
- 有「所有测试 $n$ 之和不超过 …」才可改为真单组；否则保留多询问，且不要写「多组测试数据」「数据组数 $T$」套话，改写成「第一行整数 $n$ 表示随后行数……」。
- 不要写「单组测试」「先令/先取」。
- 题面里的教学用数字例子也要换新，算对即可。

- [ ] 背景饱满且删掉后题意仍完整；无公司名/真人名
- [ ] 变量、范围、下标与边界条件无歧义
- [ ] 范围已按第四节记法规则书写，数值未跨档
- [ ] I/O 与标程一致，字符集未改
- [ ] 样例可被标程跑通；改写时未复用原样例
- [ ] 数字已反引号、公式已 `$...$`；输入输出在代码块内
